## 新案例记录格式

建议记录：

```markdown
# 案例名称

一句话介绍作品用途与可借鉴内容。

## 观看与来源
- 成片：
- 作者与原始来源：
- 源码 / 下载：有则链接；没有则明确说明

## 制作信息
- 入口：Studio / HyperFrames 框架 / 其他
- 输入与依赖：
- 版本与复现步骤：

## 验证边界
- 链接核对 / 作者记录 / 本人实际执行：
- 日期、平台与版本：
- 未验证或限制：

## 归属与许可
- 代码、文字与素材分别指向原许可。
- 概念界面与演示数据明确标注。
```

收录不代表维护者亲自运行过全部工程，也不代表原始许可允许商业使用。没有源文件的灵感作品可以收录，但不标记为模板。

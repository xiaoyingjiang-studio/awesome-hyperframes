# 知识讲解：让中文信息，有清楚的节奏

以“一句话、一幅图、一个重点”组织中文知识讲解，适合参考中文排版、字幕时序和分段阅读节奏。

## 制作与验证

这是 **HyperFrames 框架案例**，不宣称由 Studio 操作完成。工程使用 HTML、GSAP 与 Noto Sans SC 字体子集，原项目另提供中文字幕轨。

引用[原项目验证记录](https://github.com/xiaoyingjiang-studio/hyperframes-cn/blob/2cbf04a35769f80bc6dff8f6332054d63d6cc9e1/public/examples/verification.json)：2026-11-25 在 Windows、Node 24.16.0、HyperFrames 0.9.92、GSAP 3.15.1 环境中完成 lint、完整 check、实际渲染及媒体检查；输出为 960 × 540、30fps、8 秒，无音轨。本目录初始化时未重跑渲染，其他版本与环境需自行验证。

复现请先阅读[源项目案例流程](https://github.com/xiaoyingjiang-studio/hyperframes-cn/blob/2cbf04a35769f80bc6dff8f6332054d63d6cc9e1/docs/MAINTAINER.md)。改中文文案时先更新字体子集，再检查字幕时序和实际画面。

# 素材剪辑：已有素材，也能重新组织

将自产视频片段重新剪辑，叠加中文字幕和节奏提示，适合参考片段编排、文字叠加与素材引用。

## 制作与验证

这是 **HyperFrames 框架案例**，不宣称由 Studio 操作完成。所用片段由原项目自行制作，无外部人物素材或音乐；下载项目包含剪辑所需的自产片段。

引用[原项目验证记录](https://github.com/xiaoyingjiang-studio/hyperframes-cn/blob/2cbf04a35769f80bc6dff8f6332054d63d6cc9e1/public/examples/verification.json)：2026-11-25 在 Windows、Node 24.16.0、HyperFrames 0.9.92、GSAP 3.15.1 环境中完成 lint、完整 check、实际渲染及媒体检查；输出为 960 × 540、30fps、8 秒，无音轨。本目录初始化时未重跑渲染，其他版本与环境需自行验证。

复现请先阅读[源项目案例流程](https://github.com/xiaoyingjiang-studio/hyperframes-cn/blob/2cbf04a35769f80bc6dff8f6332054d63d6cc9e1/docs/MAINTAINER.md)。替换素材时一并核对路径、片段时间与素材使用权限。

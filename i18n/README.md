## Keep editions aligned

- Update the English catalog and its translations together. These Markdown files are maintained directly; there is no runtime language detection or translation service.
- Preserve original resource names, authors, source links and licenses. Translate the surrounding explanation without adding claims or rankings.
- Keep the same examples and official resources in every edition. A language edition is not a separate collection or an independently approved list.
- Keep the explicit section IDs unchanged: `start-here`, `featured-examples`, `official-resources`, `learning`, `templates-and-tools`, `discovery-and-review`, `contributing`, `attribution-and-reuse`.
- The primary catalog also retains its former Chinese section IDs so existing links from project profiles and other pages keep working. Preserve these compatibility anchors when editing.
- Paths in translated catalogs start one directory below the primary catalog. Check language links, local example notes, the shared banner and external destinations after editing.
- Clearly label the actual language of linked content. Translating the catalog does not translate the example videos, their on-screen text, source projects or maintainer guides.
- Preserve the difference between an original author's claims, source verification records and checks actually performed by maintainers. A translation must not turn an unverified claim into a test result.
- Keep live candidate counts and CI status out of permanent catalog copy. Automated leads remain in the separate candidate pool until reviewed.

Contribution guidelines are available in [English](../CONTRIBUTING.en.md) and [简体中文](../CONTRIBUTING.md). Detailed example notes and automation documentation currently remain in Chinese.
